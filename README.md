### GITTY-AI
<a href="https://github.com/tigpy/gitty-ai"><img src="https://img.shields.io/badge/repo-tigpy%2Fgitty--ai-00D4FF?style=flat-square&logo=github&logoColor=white&labelColor=0B1117" alt="gitty-ai repo" /></a>

Ingests a Git repository, parses it (Python AST + Tree-sitter), builds a typed property graph of files, functions, imports and calls, then runs OSV + secret/taint heuristics and indexes embeddings in Qdrant. Celery workers, React cockpit.

“Search the repo” is not analysis. A graph you can query is.
